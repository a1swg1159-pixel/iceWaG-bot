# 🧊 iceWaG Bot

基于 NoneBot2 + NapCatQQ 的个人 QQ 机器人，支持互动娱乐、定时推送与多款音游成绩查询。

角色设定：**冷淡猫娘**（傲娇、不耐烦但会帮忙）。

### 功能亮点

- 🎵 **全群音游查分**：CHUNITHM B30/B50、maimai DX B50、TAKUMI³ B40
- 🖼️ **统一成绩图设计**：高清曲绘、街机评级徽章、纸张式信息排版；所有生成图带有 `generated by iceWaG` 署名
- 🔐 **私聊安全绑定**：LXNS OAuth 与 TAKUMI³ 账号绑定中的敏感步骤只在私聊完成
- 🏠 **按群控制功能**：天气、新闻、答题和 UNO 等仅在 `DAILY_PUSH_GROUPS` 中启用；其他群的 `/help` 只显示实际可用功能
- 🎮 **群聊小游戏**：签到、猫猫币、二十一点、老虎机及 UNO

## 🌐 架构

```
NapCatQQ  ──WebSocket──▶  NoneBot2 (:8081)  ──▶  插件
(容器)      (反向WS)      (容器)
```

- **模式**: 反向 WebSocket — NapCat 主动连接 `ws://bot:8081/onebot/v11/ws`
- **消息格式**: Array
- **时区**: 全部统一为 `Asia/Shanghai`（北京时间）
- **容器网络**: NapCat 与 Bot 在同一 compose 网络内，通过服务名 `bot` 互相访问

## ⚡ 部署

### Windows 本地全套启动（Conda + NapCat）

双击项目根目录的 `start_bot.bat`，或在终端运行：

```bat
start_bot.bat
```

脚本会优先复用名为 `bot` 的 Conda 环境；如果不存在，会自动创建 Python 3.11 环境并安装 `requirements.txt`。它还会在首次运行时下载官方 NapCat Windows OneKey 包，询问机器人 QQ 号，自动生成 OneBot 反向 WebSocket 配置，然后同时启动 NapCat 和 NoneBot。

第一次登录时，启动器会自动打开 NapCat WebUI（自动附带本机 Token），并在二维码生成后直接打开 `qrcode.png`，用手机 QQ 扫描即可。NapCat 控制台会在 UTF-8 代码页下启动，中文日志和字符二维码也能正常显示；图片二维码不受终端字体影响。后续通常会自动恢复上次登录的账号。

NapCat OneKey 安装器内置的旧 QQ 下载地址失效时，启动器会先从腾讯官方 CDN 下载当前兼容的 x64 QQ 包，再将它交给 NapCat 安装器，不使用第三方 QQ 镜像。

只检查环境而不启动 Bot，可以运行 `start_bot.bat --check`。

本地 NapCat 的反向 WebSocket 地址应设置为：

```text
ws://127.0.0.1:8081/onebot/v11/ws
```

NapCat 中配置的 Token 必须与 `.env` 的 `ONEBOT_V11_ACCESS_TOKEN` 一致。按 `Ctrl+C` 可停止 Bot。

### 前置条件

- Docker + Docker Compose Plugin
- 一个有权限的 QQ 号

### 一键部署

```bash
bash deploy.sh
```

按提示输入 QQ 号、管理员 QQ 号等，脚本会自动生成配置、构建镜像并启动两个容器。

### 手动配置 `.env`

```env
ENVIRONMENT=production
HOST=0.0.0.0
PORT=8081
ONEBOT_V11_ACCESS_TOKEN=你的Token

# 每日推送目标群（逗号分隔的群号，留空则不推送）
DAILY_PUSH_GROUPS=123456789

# 天气查询默认城市
WEATHER_CITY=北京

# 管理员 QQ 号（用于 /reload 等管理员指令）
ADMIN_QQ=你的QQ号

# LXNS OAuth：应用选择“无回调地址”，API 权限勾选 read_user_profile、read_player、write_player
LXNS_OAUTH_CLIENT_ID=9a6be364-2c97-4773-89ec-8c7d04fcbd41
LXNS_OAUTH_CLIENT_SECRET=你的OAuth应用密钥（使用PKCE时可留空）

# 可选：服务器直连舞萌机台服务失败时使用的 HTTP 代理
MAIMAI_ARCADE_HTTP_PROXY=
```

> ⚠️ NapCat 配置 `napcat/config/onebot11_<QQ号>.json` 中的 `token` 必须与 `.env` 中的 `ONEBOT_V11_ACCESS_TOKEN` 一致。`deploy.sh` 会自动保持同步。

### LXNS OAuth 绑定

在 LXNS 开发者面板创建 OAuth 应用时勾选“无回调地址”，API 授权选择
`read_user_profile`、`read_player` 和 `write_player`。不要申请 `read_user_token`、
邮箱或 OpenID 权限。`write_player` 仅用于用户主动执行机台扫码更新。将应用 ID
写入 `.env` 后重启 Bot。用户私聊发送
`/chu bind` 或 `/mai bind` 获取授权链接，再用对应的 `bind <授权码>` 完成绑定；
两个游戏共用这一份 OAuth 授权。Access Token 到期时 Bot 会自动轮换 Refresh Token。
以前只授予读取权限的用户需要重新执行一次 `bind`，才能使用扫码更新。

### 扫码登录

部署后浏览器打开 `http://服务器IP:6099/webui/`，点击「登录」，手机 QQ 扫码即可。

### 常用命令

```bash
docker compose up -d --build   # 重新构建并启动（代码改动后）
docker compose up -d --force-recreate   # 仅重建容器不重建镜像（env 改动后）
docker compose logs -f bot     # 查看 bot 日志
docker compose logs -f napcat  # 查看 napcat 日志
docker compose restart         # 重启（不重建）
docker compose down            # 完全停止
```

### 时区说明

两个容器均设置 `TZ=Asia/Shanghai`，所有定时任务和 `/time` 指令均使用北京时间。部署后发 `/time` 可验证。

### 🎵 Chunithm 中二节奏（`/chu`）

基于 [lxns.net](https://maimai.lxns.net) API，支持成绩查询与高清图片生成。

**统一视觉：** 米白纸张底、黑色硬边框、橙青双色章节、街机评级徽章与白字 Rating 条；B30、B50、推分、装福和舞萌 B50 使用同一套信息层级。所有生成图片底部统一标注 `generated by iceWaG`。

| 子命令 | 功能 |
|---|---|
| `/chu bind` | 获取 LXNS OAuth 授权链接 |
| `/chu bind <授权码>` | 完成 OAuth 绑定 |
| `/chu unbind` | 解除 OAuth 绑定（舞萌与中二共用） |
| `/chu b30` | 生成 Best 30 成绩图片（评分最高的 30 首曲） |
| `/chu b50` | 生成 Best 50 成绩图片（旧曲 30 + 新曲 20） |
| `/chu score <任意等级或定数>` | 生成该档全部已游玩成绩列表；支持所有整数档、`+` 档和一位小数定数 |
| `/chu 推分` | 随机抽一首有成绩的歌曲，展示曲绘与分数 |
| `/chu 装福` | 随机抽一首单曲评分高于你当前 Rating 的上分曲 |

> 💡 只支持 OAuth，不再接受个人 API Token 或开发者 Token。查分可在任意群使用，`bind` 授权绑定请在私聊完成。

插件路径: `src/plugins/chunithm_b30/`

### 🔷 TAKUMI³（`/takumi` / `/t3`）

通过 TAKUMI³ 官方账号后端直接查询成绩，并按游戏 Rating 公式生成带官方曲绘的 Best 40 图片，不需要用户上传记录。视觉沿用现有 B50 的信息卡片结构，同时加入深蓝轨道透视、青/品红高亮和立方体元素。

| 子命令 | 功能 |
|---|---|
| `/takumi bind <登录邮箱> <密码>` | 私聊 Bot，一次性登录并创建 Bot 专用授权 |
| `/takumi b40` | 查询并生成 Best 40 图片 |
| `/takumi unbind` | 撤销 Bot 授权并解除绑定 |

> 🔒 查分可在任意群使用，`bind` 只能在私聊使用。密码仅用于首次登录，插件不会把它写入绑定文件；Bot 保存随机生成、可通过 `unbind` 撤销的专用凭据。内置社区定数快照包含 391 张 13.0 以上谱面，并通过官方歌曲 ID 目录匹配；若账号不足 40 张可匹配成绩，图片和消息会标记 `PARTIAL`。生成图片底部统一标注 `generated by iceWaG`。

插件路径: `src/plugins/takumi_b40/`

## 💻 远程开发

生产代码在 Ubuntu 服务器上，可通过 VSCode Remote-SSH 直接编辑。

1. `Ctrl+Shift+P` → `Remote-SSH: Open SSH Configuration File`
2. 添加：
```
Host qq-bot
    HostName 你的服务器IP
    User ubuntu
```
3. `Ctrl+Shift+P` → `Remote-SSH: Connect to Host` → 选 `qq-bot`
4. 打开 `/opt/qq-bot`

修改后执行 `docker compose up -d --build` 即可生效。

## 🐛 常见问题

| 问题 | 原因 / 解决 |
|---|---|
| NapCat 频繁被踢下线 | QQ 反作弊检测。检查手机 QQ 是否频繁切换网络，固定 NapCat 镜像版本，确保仅一个终端在线 |
| `/time` 显示的时间不对 | 容器 TZ 未生效，检查 `docker-compose.yml` 是否设置 `TZ=Asia/Shanghai` |
| 定时推送时间不对 | 同上，重建容器 `docker compose up -d --force-recreate` |
| WebSocket 连接失败 | 检查 `.env` 和 NapCat 配置中的 Token 是否一致 |
| `/chu`、`/mai` 成绩指令报错 | 检查是否已完成 OAuth 绑定，并在 LXNS 同步对应游戏成绩 |
| `/takumi` 查不到成绩 | 私聊重新执行 `/takumi bind <登录邮箱> <密码>`，并确认该账号在普通模式已有游玩成绩 |
| 邮件绑定提示连接失败 | 检查授权码是否正确（不是登录密码），IMAP 服务是否已在邮箱设置中开启 |
| 邮件通知群里收不到 | 检查 `DAILY_PUSH_GROUPS` 是否配置，用户是否在对应群里 |
| 二十一点/老虎机没反应 | 需要 `@bot` 触发指令，如 `@bot /二十一点 100` |
